PDF to Compendium

Release %RELEASE% (UTC) · Source code · License (GNU AGPL-3.0)

Converts PDFs into a Foundry VTT module of compendium packs for the dnd5e system (5th edition character options, 2014 or 2024 rules) or the wh40k-rpg system. Everything runs in this browser tab: the files are never uploaded anywhere. Install the module as described in Install in Foundry; several can be installed side by side.

1. Choose PDFs

Choose the game line or ruleset whose schema each PDF is written in. One module holds one system's packs.

    Resources

    Choose PDFs to see the memory a job needs.

    OCR reads one page per core. A memory budget runs fewer pages at once to fit it (an approximate fit). The output is the same either way.

    4. Install in Foundry
    
                
      
                    
    1. 
                        Install the game system the module is for, if you have not:
                        dnd5e (Foundry v14 or later) or wh40k-rpg (Foundry
                        v13 or later). The module only appears in worlds that use that system.
                    
      2. 
                    
    2. 
                        Unzip the downloaded file. It holds one folder, named like
                        pdf-compendium-1a2b3c4d5e6f.
                    
      3. 
                    
    3. 
                        Put that folder in the Data/modules folder of your Foundry user data. On
                        Foundry's setup screen, the Configuration tab shows where your user data is.
                        On a hosted server, upload the folder into Data/modules with your host's
                        file manager.
                    
      4. 
                    
    4. 
                        Restart Foundry, or go back to its setup screen. The module is listed under
                        Add-on Modules as “PDF Compendium: …” with the converter release in its name.
                    
      5. 
                    
    5. 
                        Launch your world, open Game Settings → Manage Modules, tick the module and
                        save.
                    
      6. 
                    
    6. 
                        The packs are in the Compendium Packs sidebar tab, in a folder named “PDF
                        Compendium …”.
                    
      7. 
                
    
                
    
                    Each conversion is its own module, so converting again (after a new converter release,
                    say) gives a new folder beside the old one. Disable or delete the old module so the packs
                    are not listed twice. When a newer converter release is out, Foundry tells the GM once
                    when the world loads.
