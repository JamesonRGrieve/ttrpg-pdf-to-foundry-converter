PDF to Compendium

Release %RELEASE% (UTC) · Source code · License (GNU AGPL-3.0)

Converts PDFs into a Foundry VTT module of compendium packs for the dnd5e system (5th edition character options, 2014 or 2024 rules) or the wh40k-rpg system. Everything runs in this browser tab: the files are never uploaded anywhere. Follow the three steps below.

1. Choose PDFs

  1. Drop your PDF files on the box below, or click it to pick them. You can add several.
  2. Next to each file, pick what the book is for: dnd5e-2014 or dnd5e-2024 for a 5th edition book (whichever rules it uses), or the game-line code (dh2, dh1, rt, dw, ow, bc or im) for a book of the wh40k-rpg system. All files in one batch must be for the same system.
  3. Wrong file? Click its × to take it out.
  4. Leave Resources as it is unless your computer struggles (see step 2).
  5. Click Convert.
    Resources

    Choose PDFs to see the memory a job needs.

    The converter reads one page per core. A memory budget reads fewer pages at once to fit it (an approximate fit). The result is the same either way; only the speed changes.

    2. Wait for Completion

    • Keep this tab open until the status below says Done. Don't close it, reload it, or let the computer sleep, or you will have to start again.
    • Every page is read like a scan, so a big book takes a while. The bar shows how far it has got; after the last page the module still has to be put together, so wait for Done.
    • If it says the browser ran out of memory: close other programs and other browser windows and tabs, then convert again. Fewer CPU cores or a smaller memory budget in step 1 also uses less memory.

    No file chosen.

    Your browser ran out of memory. Close background programs, especially other Chrome windows and tabs, then try again. A lower memory budget or fewer CPU cores also uses less memory.

    1. 
                        When the conversion is done, click Download module (.zip) above. (The
                        button only appears once it is finished.)
                    
      2. 
                    
    2. 
                        Make sure Foundry has the game system the module is for: dnd5e (needs
                        Foundry v14 or later) or wh40k-rpg (needs Foundry v13 or later). If
                        not, install it from Foundry's setup screen: Game Systems → Install System.
                    
      3. 
                    
    3. 
                        Find Foundry's modules folder. On Foundry's setup screen, the
                        Configuration tab shows the User Data Path; the folder you want is
                        Data/modules inside it. Unless you changed it, that is:
                        
        
                            
      • Windows: %LOCALAPPDATA%\FoundryVTT\Data\modules
        • 
                            
      • macOS: ~/Library/Application Support/FoundryVTT/Data/modules
        • 
                            
      • Linux: ~/.local/share/FoundryVTT/Data/modules
        • 
                        
      
                        On a hosted server, use your host's file manager to open Data/modules
                        there, not a folder on your own computer.
                    
      4. 
                    
    4. 
                        Unzip the downloaded file into that modules folder. You get one new
                        folder named like pdf-compendium-1a2b3c4d5e6f.
                    
      5. 
                    
    5. 
                        Check: open that new folder. You must see
                        module.json right there. If you see another
                        pdf-compendium-… folder instead, your unzip tool made a folder inside a
                        folder: move the inner one up into modules and delete the empty outer
                        one.
                    
      6. 
                    
    6. 
                        Quit Foundry completely and start it again. (If it runs on a server,
                        go back to its setup screen.) Foundry only notices new modules then.
                    
      7. 
                    
    7. 
                        On the setup screen, open Add-on Modules. You should see
                        PDF Compendium: … with the converter release in brackets.
                    
      8. 
                    
    8. 
                        Launch a world that uses the matching game system. In it, open
                        Game Settings → Manage Modules, tick PDF Compendium: …, and
                        click Save Module Settings. The world reloads.
                    
      9. 
                    
    9. 
                        Open the Compendium Packs tab in the right-hand sidebar (the book icon). Your
                        packs are in the folder named PDF Compendium ….
                    
      10. 
                
    
                
    Not showing up?
    
                
      
                    
    • 
                        Not in Add-on Modules: redo the check in step 5, then restart Foundry again.
                    
      • 
                    
    • 
                        Listed, but not in your world's Manage Modules: the world uses a different
                        game system from the one you picked in step 1, or your Foundry is older than the
                        system needs.
                    
      • 
                    
    • 
                        Packs listed twice: you have an older conversion installed too. Each conversion is its
                        own module; disable or delete the old one.
                    
      • 
                
    
                
    
                    When a newer converter release is out, Foundry tells the GM once when the world loads.
                    Convert your PDFs again here for the new results, install the new module, and delete the
                    old one.
