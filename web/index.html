PDF to Compendium

Converts PDFs into a Foundry VTT module of compendium packs for the dnd5e system (5th edition character options, 2014 or 2024 rules) or the wh40k-rpg system. Everything runs in this browser tab: the files are never uploaded anywhere. Unzip the module into Foundry's Data/modules folder; several can be installed side by side.

1. Choose PDFs

Choose the game line or ruleset whose schema each PDF is written in. One module holds one system's packs.

    Resources

    OCR reads one page per core. A memory budget runs fewer pages at once to fit it (an approximate fit). The output is the same either way.
